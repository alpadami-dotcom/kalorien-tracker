                Kurzbefehl einrichten (einmalig)
                1. App Kurzbefehle öffnen, unten „Kurzbefehle“, oben rechts +.
                2. Oben auf den Namen tippen → Umbenennen → genau Schritte kopieren.
                3. Suche: Health → Health-Messungen suchen (nicht „protokollieren“).
                4. Typ Schritte, Startdatum ist heute, Gruppierung nach Tag.
                5. Suche: Statistik → Statistik berechnen → Summe.
                6. Suche: Zwischenablage → In Zwischenablage kopieren.
                7. ▶ unten rechts zum Testen, Health-Zugriff erlauben. Speichert von selbst.
